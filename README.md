
# ShadowFox ML Internship

A collection of machine learning projects developed as part of the ShadowFox Machine Learning Engineer Internship.

## Projects

### 1. Beginner: Autocorrect System
A Python-based text correction system that corrects spelling mistakes and provides next-word predictions using an n-gram language model.

**Technologies:** Python, pyspellchecker, n-gram language modeling

**Features:**
- Spelling correction
- Correction suggestions
- Next-word prediction
- Unit tests

**Project folder:** `Beginner/Autocorrect-System/`

### 2. Intermediate: Store Sales and Profit Analysis
A data analysis project using the Sample Superstore dataset to explore sales trends, customer segments, product categories, and profitability.

**Technologies:** Python, Pandas, NumPy, Matplotlib, Seaborn, Plotly

**Features:**
- Data cleaning and quality checks
- Monthly sales and profit analysis
- Category and customer segment comparisons
- Subcategory profitability analysis
- Interactive visualizations
- Automated business insights report

**Project folder:** `Intermediate/Store-Sales-Analysis/`

### 3. Advanced: NLP Language Model
An NLP project involving a selected language model, experiments with varied inputs, research questions, and analysis of strengths, limitations, and ethical considerations.

**Planned technologies:** Python, Jupyter Notebook, NLP libraries

**Project folder:** `Advanced/NLP-Language-Model/`

## Getting Started

Each project has its own folder and may have its own dependencies.

1. Clone this repository.
2. Open the project folder you want to explore.
3. Follow the setup instructions in that project's README.
4. Install the required dependencies.
5. Run the project using its documented commands.

- Perform data cleaning, analysis, and visualization.
- Evaluate model behavior using different inputs.
- Document findings, limitations, and ethical considerations.
